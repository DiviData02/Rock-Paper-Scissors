# 🎮 Rock Paper Scissors Game

A simple command-line **Rock Paper Scissors** game developed in **Python** using the **random module** and **conditional statements**. This project was created as a beginner-friendly exercise to understand Python programming fundamentals and game logic.

---

## 📌 About the Project

This game allows a user to play **Rock, Paper, Scissors** against the computer. The computer randomly selects one of the three choices, and the program compares both choices using conditional statements to determine the winner.

This project demonstrates the use of:

- Python basics
- User input handling
- Random number generation
- Conditional statements (`if`, `elif`, `else`)
- Simple game logic

---

## ✨ Features

- 🎯 User vs Computer gameplay
- 🎲 Random computer choice using Python's `random` module
- ⚖️ Automatic winner determination
- 🤝 Draw detection
- 💻 Simple command-line interface
- 🟢 Beginner-friendly implementation

---

## 🛠️ Technologies Used

- Python 3
- Python IDLE
- `random` module
